# College Hackathon Management System — Frontend

Standalone HTML/CSS/JavaScript frontend for the College Hackathon Management System.

## Run Locally
```bash
python3 -m http.server 3000
```
Open `http://127.0.0.1:3000` in your browser.

## Backend Configuration
By default, `app.js` connects to `http://127.0.0.1:8000`. To point to a deployed backend URL, update `API_BASE` at the top of `app.js`.
